# Then vs Now

An interactive, static website that compares housing, pay and living costs for your parents' generation with yours, using official US data.

Pick two birth years and a home-buying age. The site then shows a scorecard with inflation-adjusted home prices, incomes, price-to-income ratios, mortgage payments, years needed to save a down payment, rent, homeownership and more. Below the scorecard are charts from 1965 to today, a "fair points on both sides" summary and a table of every year. Your settings are saved in the URL, so you can send someone a link to a specific comparison.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then pick `master` and `/ (root)`.
3. The site will be live at `https://<user>.github.io/costs/`.

No build step is needed. The page loads Chart.js from jsDelivr and reads `data/data.json`.

To preview it locally, run `python3 -m http.server` and open http://localhost:8000.

## Data

`data/data.json` is generated by `scripts/build_data.py`, which downloads from these sources:

| What | Source |
|---|---|
| Median home sales price | Census/HUD via FRED (`MSPUS`) |
| 30-year mortgage rate | Freddie Mac via FRED (`MORTGAGE30US`) |
| Median household income (all, and householders 25–34) | Census CPS Tables H-5 and H-10, 1967 onward |
| Homeownership, all ages and under 35 | Census HVS (`RHORUSQ156N`, Table 19) |
| Median gross rent | Census decennial census 1960–2000, with the CPI rent index used between census years and after 2000 |
| CPI (all items, rent, tuition, medical, food, gas, cars, apparel) | BLS via FRED |
| Minimum wage, hourly earnings, productivity, real compensation | DOL/BLS via FRED |
| Personal saving rate | BEA via FRED |
| Student loans outstanding | Federal Reserve via FRED (`SLOAS`) |

To refresh the data:

```sh
pip install openpyxl
python3 scripts/build_data.py
```

### Caveats

- These are national medians. Local markets can be very different.
- Mortgage payments include principal and interest only. Property taxes, insurance and PMI are not included.
- "Years to save" assumes a flat savings rate, no investment returns and no help from family.
- Rent after 2000 is extended with the CPI rent index. For 2024 this gives about $1,375 a month, which is somewhat below the Census American Community Survey figure. The rent figures are therefore conservative and slightly favor the "it was just as hard" side.
